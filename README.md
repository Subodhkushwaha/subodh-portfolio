# Subodh Kushwaha: Portfolio (React + Vite)

## Run it
```bash
npm install
npm run dev        # opens http://localhost:5173
npm run build      # production build in /dist
```

## Edit your content
All text, links, projects and skills live in `src/data.js`.
Replace the `'#'` values (LinkedIn, LeetCode, GeeksforGeeks, BookMyShow repo) with your real URLs.

## Deploy
Push this folder to GitHub, then import it on https://vercel.com (framework: Vite). No settings needed.

## Files
- `index.html`: page shell and Google Fonts
- `src/main.jsx`: React entry
- `src/App.jsx`: all sections as React components
- `src/components/ParticleBackground.jsx`: animated background (canvas + glowing blobs)
- `src/styles.css`: all styling, light and dark theme
- `src/data.js`: your content
